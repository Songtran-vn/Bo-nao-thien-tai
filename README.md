## 🚀 Cách sử dụng

### Chạy local
1. Clone repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/brilliant-minds.git
   cd brilliant-minds
   ```
2. Mở `index.html` bằng trình duyệt (Chrome / Edge / Firefox)

### Deploy lên GitHub Pages
1. Vào **Settings** → **Pages**
2. Source: chọn `main` branch, thư mục `/ (root)`
3. Nhấn **Save** — trang web sẽ live tại:
   ```
   https://YOUR_USERNAME.github.io/brilliant-minds
   ```

## ⚙️ Yêu cầu

- Trình duyệt hiện đại (Chrome 90+, Firefox 88+, Edge 90+)
- Kết nối internet (để gọi Anthropic API)
- Ứng dụng sử dụng **Claude Sonnet** API — đảm bảo domain của bạn được phép gọi `api.anthropic.com`

## 🛠️ Công nghệ

- **Vanilla HTML/CSS/JS** — không cần framework, không cần build
- **Anthropic Claude API** (`claude-sonnet-4-20250514`)
